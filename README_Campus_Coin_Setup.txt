CAMPUS COIN - SIMPLE SETUP

1. Create a MySQL database using the same database name written in your .env file.
2. Check DB_DATABASE, DB_USERNAME and DB_PASSWORD in .env.
3. Open the project folder in CMD/Terminal.
4. Run: php artisan migrate
5. Run: php artisan serve
6. Open the address shown by Laravel in the browser.
